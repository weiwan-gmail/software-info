# Awesome lists and company-account catalog

Checked: evening of 2026-08-29 (PT). Star counts are from the GitHub API then, and will change.

How to use it: talk through awesome lists by number. Finish one before starting the next. For each list, mine individual repos first, then combinations (repo-to-repo, or against a current popular project). Company accounts and personal accounts are two other lines. Do not interrupt the awesome order.

Personal accounts (toys / tools) are section 6.

The master index [sindresorhus/awesome](https://github.com/sindresorhus/awesome) (501,182 star) is not a talk of its own.

- Stars are an API snapshot from the evening of 2026-08-29 PT, not a ranking conclusion.
- Group A “like Tailscale” is a browsing judgment: small projects next to the main product that you can play with on their own. HashiCorp is more like a product-line open source, not the same class.
- `superfly/sprites` came up in conversation then. After checking, that repo does not exist. Only [superfly/sprites-docs](https://github.com/superfly/sprites-docs) (50 star).
- fCWT’s 34–120× speedup is the author’s paper/README claim. This table does not treat it as reproduced.
- awesome-orgs / awesome-organizations have very low stars. Use them as directories only.
