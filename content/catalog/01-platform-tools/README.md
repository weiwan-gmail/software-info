### Embeddable JS runtimes (Go)

**Open source**

| Repo | star (2026-11-08) | License | Notes |
|---|---:|---|---|
| [MoeForge/moejs](https://github.com/MoeForge/moejs) | 474 | Apache-2.0 | Embeddable **pure-Go** JavaScript runtime for in-process plugins: ES modules, async/await, Go interop; host-controlled imports; interrupt from any goroutine; per-runtime memory limits. Optional `eventloop` and `webapi` packages; optional `node` fs stays inside a host directory when you install it. **Not** a Node.js replacement. `CompileTS` strips types the way Node does; enums, value namespaces, and other TypeScript that changes runtime semantics fail. ## 1.9 Headless engines, HTML toolkits, and CDP controllers (harvest 2026-11-22)

Stars as of 2026-11-22 GitHub API. These are **not** [ego lite](#18-agent-browsers-harvest-2026-11-22) (a desktop GUI browser + skill/SDK). Frozen [11-lang-compare](../11-lang-compare/README.md) not expanded. Do not install these programs from this harvest. Vendor speed/memory/token numbers are not independent evidence.

**How the classes differ**

| Class | What it is | What it is not | This harvest |
|---|---|---|---|
| Desktop agent browser | A GUI browser a human uses; agents attach | Not a headless library | ego lite §1.8 |
| Independent headless engine | Own engine (not a Chromium/WebKit fork) | Not “Rust replacements” as a group — languages differ | Lightpanda (**Zig**), Obscura (**Rust**), Moli (**Rust**) |
| Embeddable web engine | Engine meant to embed in apps | Not a drop-in headless Chrome | Servo |
| HTML/CSS toolkit | Modular layout/paint; incomplete browser product | Not WebRTC/WebSocket/storage as a browser | Blitz (**Rust**; **beta**) |
| Experimental WASM engine | Runs on Cloudflare Workers; speaks CDP | Not a local daily driver; paid plan for cloud | Kitesurf (Rust compiled to WASM + TypeScript) |
| CDP / DevTools controller | Drives Chrome or another engine over CDP | Does **not** replace Chromium by itself | rust-headless-chrome, agent-browser |
