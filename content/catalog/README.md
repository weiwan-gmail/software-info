用法：先看大领域，再进子目录。子目录里再分类。每一类同时收三种：

- **开源**
- **免费闭源**（能用，源码不公开或只开一部分）
- **收费**（买断、订阅、硬件要买、共享软件）

不编价格。收费只写形态。细节仍在原来的分表。
