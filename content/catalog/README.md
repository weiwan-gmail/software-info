# Catalog

Checked: 2026-08-29 PT. Stars are a GitHub API snapshot from that moment and will change. This is a domain tree, not an exhaustive ranking.

How to use it: pick a domain, then a subdirectory. Each subdirectory splits further. Every class collects all three:

- **Open source**
- **Free closed-source** (usable; source is closed or only partly open)
- **Paid** (buyout, subscription, hardware you buy, shareware)

No invented prices. Paid entries only record the form. Detail still lives in the older tables.

## How this grows

New items land in the matching subdirectory first, marked open source / free closed-source / paid. Add a row here only if it is a new domain. Record format is in [tools-by-platform.md](../tools-by-platform.md) section 8. Do not check Sysinternals / Rufus for new versions.
