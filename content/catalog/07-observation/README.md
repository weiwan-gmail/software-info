# 7. 观测与空间

## 7.1 星图 / 桌面天文

**开源：** Stellarium 9,907 · KStars 284 · INDI 451 · INDIGO 201

**免费闭源 / 收费**

| 名字 | 官网 | 形态 | 开源对标 |
|---|---|---|---|
| SkyView | App Store / Play | 商店买断（美区付费榜出现过） | Stellarium |
| PhotoPills | [photopills.com](https://www.photopills.com/) | 买断 | 天文计算；UI 是产品 |
| SkySafari | [skysafariastronomy.com](https://skysafariastronomy.com/) | App 分层收费 | Stellarium / KStars |
| Stellarium Plus 等移动壳 | 各商店 | 常和桌面开源不是同一授权 | 桌面 Stellarium 开源 |

## 7.2 GIS / 地图

**开源：** QGIS 14,303 · OSM 网站 2,815 · OsmAnd 5,939

**免费闭源**

| 名字 | 官网 | 形态 |
|---|---|---|
| Google Maps | maps.google.com | 消费端免费闭源；API 另计费 |
| Google Earth | [earth.google.com](https://earth.google.com/) | 桌面/网页现为免费闭源 |
| Apple Maps | 系统自带 | 免费闭源 |

**收费**

| 名字 | 官网 | 形态 | 开源对标 |
|---|---|---|---|
| ArcGIS | [esri.com](https://www.esri.com/) | 订阅 / 企业授权 | QGIS |
| Google Maps Platform | [developers.google.com/maps](https://developers.google.com/maps) | API 计费 | OSM / 自建瓦片 |
