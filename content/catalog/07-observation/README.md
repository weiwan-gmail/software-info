# 7. Observation & space

## 7.1 Sky charts / desktop astronomy

**Open source:** Stellarium 9,907 · KStars 284 · INDI 451 · INDIGO 201

**Free closed-source / paid**

| Name | Site | Form | Open-source counterpart |
|---|---|---|---|
| SkyView | App Store / Play | store buyout (has appeared on the US paid chart) | Stellarium |
| PhotoPills | [photopills.com](https://www.photopills.com/) | buyout | astronomical calculation; the UI is the product |
| SkySafari | [skysafariastronomy.com](https://skysafariastronomy.com/) | app, tiered paid | Stellarium / KStars |
| Stellarium Plus and similar mobile shells | various stores | often not the same license as desktop open source | desktop Stellarium is open source |

## 7.2 GIS / maps

**Open source:** QGIS 14,303 · OSM website 2,815 · OsmAnd 5,939

**Free closed-source**

| Name | Site | Form |
|---|---|---|
| Google Maps | maps.google.com | consumer side free closed-source; API billed separately |
| Google Earth | [earth.google.com](https://earth.google.com/) | desktop/web now free closed-source |
| Apple Maps | bundled with the OS | free closed-source |

**Paid**

| Name | Site | Form | Open-source counterpart |
|---|---|---|---|
| ArcGIS | [esri.com](https://www.esri.com/) | subscription / enterprise license | QGIS |
| Google Maps Platform | [developers.google.com/maps](https://developers.google.com/maps) | API billing | OSM / self-hosted tiles |
