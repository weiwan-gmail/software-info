# 4. 制造

细表：[oshw-and-print.md](../../oshw-and-print.md)。作业是切片、固件、刀路，不是再下一个 STL。

## 4.1 清单与模型站

开源清单：awesome-3d-printing 1,940。

模型站（目录，不是仓库）：Printables、Thingiverse、MakerWorld。记模型和许可证。

## 4.3 切片

**开源：** PrusaSlicer 9,250 · OrcaSlicer 15,522（Cura 也是开源，未在本批核 star）

**收费：** [Simplify3D](https://www.simplify3d.com/) 买断切片。Bambu 打印机是硬件订阅/买断生态；Studio 本身有开源仓，不单列成闭源。

## 4.4 打印机机械与固件

**开源：** Voron-2 4,514 · Klipper 11,850 · OctoPrint 9,084 · Mainsail 2,203

**收费：** Prusa / Bambu / Creality 整机（[prusa3d.com](https://www.prusa3d.com/) · [bambulab.com](https://bambulab.com/)）。Voron 是开源机械，零件自己买。

## 4.5 CNC

**开源：** Universal-G-Code-Sender 2,250 · cncjs 2,640

**收费：** Mastercam、Fusion 里的 CAM、各家桌面 CNC 整机。
