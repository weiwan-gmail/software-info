# 4. Fabrication

Detail table: [oshw-and-print.md](../../oshw-and-print.md). The homework is slicers, firmware, and toolpaths, not another STL.

## 4.1 Lists and model sites

Open-source lists: awesome-3d-printing 1,940.

Model sites (directories, not repos): Printables, Thingiverse, MakerWorld. Record the model and the license.

## 4.3 Slicers

**Open source:** PrusaSlicer 9,250 · OrcaSlicer 15,522 (Cura is also open source; stars not checked in this batch)

**Paid:** [Simplify3D](https://www.simplify3d.com/) slicer buyout. Bambu printers are a hardware subscription/buyout ecosystem. Studio itself has an open-source repo, so it is not listed as closed-source on its own.

## 4.4 Printer mechanics and firmware

**Open source:** Voron-2 4,514 · Klipper 11,850 · OctoPrint 9,084 · Mainsail 2,203

**Paid:** Prusa / Bambu / Creality complete machines ([prusa3d.com](https://www.prusa3d.com/) · [bambulab.com](https://bambulab.com/)). Voron is open-source mechanics. You buy the parts yourself.

## 4.5 CNC

**Open source:** Universal-G-Code-Sender 2,250 · cncjs 2,640

**Paid:** Mastercam, CAM inside Fusion, various desktop CNC complete machines.
